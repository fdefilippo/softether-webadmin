# softether-webadmin

A web administration daemon for [SoftEther VPN Server](https://www.softether.org/),
talking to the server's JSON-RPC API.

**Status: work in progress.** Nothing is usable yet; milestone 1 (foundations and
first access) is under way.

Design: see [`docs/superpowers/specs/2026-11-05-softether-webadmin-design.md`](docs/superpowers/specs/2026-11-05-softether-webadmin-design.md).
